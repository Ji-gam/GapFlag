## 2-7(신설). 화면 정리 (PR #30, 2026-09-04)

**대상 파일**: `app/templates/base.html`·`detail.html`·`matrix.html`·`search.html`·`about.html`.
`app/apis/cmp_pages.py`는 무변경 — 이미 넘어오던 데이터를 화면이 안 그리고 있었을 뿐이라
서비스·라우터 쪽은 손댈 필요가 없었다.

- **`detail.html` 깨진 링크 수정**: 근거 카드에 `{% if c.source_url %}` 가드 추가. `cmp_service._card()`가
  근거 없는 항목엔 `source_url`도 `None`으로 돌려주는데([app/services/cmp_service.py](../app/services/cmp_service.py)),
  템플릿이 무조건 `<a href="{{ c.source_url }}">`를 그려 `None (None)` 링크가 떴었다.
- **`detail.html` 지수 요약 추가**: 상단에 위험지수/기회지수 값 + 커버리지%(`n/전체`) 박스.
  지수가 NULL이면 회색 처리. 새 계산 없음 — 라우터가 이미 넘기던 `score` dict를 그리기만 함.
- **`detail.html` 기회 축 NULL 문구 분리**: 위험 축 "위험이 없다는 뜻이 아닙니다" / 기회 축
  "확인하지 못했습니다 — 기회가 없다는 뜻이 아닙니다". 두 블록은 Jinja 매크로 하나로 합쳐
  중복 제거.
- **`matrix.html` 반응형 SVG**: `width="520" height="520"` 고정 속성 제거, `viewBox`만으로
  `max-width: 520px; width: 100%; height: auto`. 모바일 폭에서도 잘리지 않음(확인 완료).
- **`base.html` 공통 헤더**: 화면 4개에 제각각 있던 임시 내비게이션 줄(`<p><a>...</a></p>`)을
  지우고, 제품명 + 검색/매트릭스/산식 3링크 공통 헤더로 통일.

**검증**: `pytest` 48개 통과 (회귀 없음, 템플릿만 변경) · `ruff format/check`·`mypy` 통과 ·
브라우저로 4개 화면 데스크톱·모바일 확인, R4 카드에서 깨진 링크가 사라진 것과 지수 요약
박스 렌더를 스크린샷으로 대조.

**주의**: `app/templates/`는 정보교 담당 경로다(CLAUDE.md §파일 소유권). PR로 올려 머지는
됐지만, 이 세션에서는 정보교 본인 확인을 별도로 받지 않았다 — 다음 세션에서 확인 여부를
