# STEP 3 — 사업계획서 초안

작성일 2026-08-29 · STEP 1(시장검증), STEP 2(고객가설·사업기회) 결과를 반영해 사업아이템을 구체화

---

## 1. 사업아이템명

Gap & Flag (갭앤플래그)

## 2. 사업 개요

- 어떤 고객의: 동물약 개발기업 R&D팀에서 신약 후보 성분을 초기 스크리닝하는 연구원의
- 어떤 문제를: 종간 대사 차이를 반영한 위험·기회 데이터가 6개 공개 소스에 흩어져 있어 성분 단위로 교차검증할 수 없다는 문제를
- 어떤 방식으로 해결하는 사업인지: 성분명(active ingredient)을 조인 키로 6개 공개 데이터소스를 자동 수집·정규화해, 위험×기회 2×2 매트릭스와 근거 카드(출처 링크 포함)로 한 화면에서 보여주는 웹 기반 스크리닝 도구

## 3. 문제인식

- **고객이 겪고 있는 핵심 문제**: 후보 성분이 "위험한지"와 "아직 아무도 안 건드린 공백인지"를 동시에 판단하려면 openFDA·Open Targets·Green Book·EPO·Europe PMC·ClinicalTrials.gov를 개별 조회하고 수작업으로 대조해야 함
- **현재 해결 방식의 한계**: 인체 전용 DB(Cortellis 등)는 종 특이적 위험을 반영하지 않고, 무료 툴(Open Targets)은 종 축이 없으며, 수의 임상 데이터(VetCompass)는 진료 역학용이라 타깃 발굴에 안 맞음. 현재 실무자가 정확히 무엇으로 이 공백을 메우는지는 [추가 검증 필요]
- **데이터·시장검증에서 확인한 근거**:
  - 조사한 경쟁 도구 12개 중 종 축을 가진 도구는 발견되지 않음
  - 종간 대사 차이가 과학적으로 유의미하다는 동료심사 문헌 근거 존재 (Court MH 2013 — 사람 데이터가 개·고양이 소실 반감기 예측에 대부분 부적합)
  - 대비 사실: 최근 FDA 승인 동물 신약은 대부분 인체 임상 이력 자산의 재활용

## 4. 핵심 고객

- **1차 타깃 고객**: 동물약 개발기업 R&D팀의 신약 후보 초기 스크리닝 담당 연구원
- **고객이 해당 서비스를 필요로 하는 상황**: 후보 성분 여러 개 중 다음 단계로 넘길 것을 고르거나, 인체 자산의 동물용 재활용 가능성을 검토하는 시점
- **핵심 니즈**: 성분 단위로 위험과 기회를 한 화면에서 비교하고, 그 판단의 근거(원문 링크)까지 바로 확인하고 싶다

## 5. 해결방안

- **제공할 제품/서비스**: 웹 기반 성분 스크리닝 도구 (FastAPI + Jinja2 서버 렌더링)
- **문제 해결 방식**: 성분명 입력 → 6개 소스 데이터를 정규화된 위험지수(R1~R4)·기회지수(O1~O3)로 환산 → 2×2 매트릭스에 배치
- **핵심 기능**: S1 2×2 매트릭스(인라인 SVG), S2 성분 상세+근거 카드, S3 후보 비교(P1, 잘라도 됨)

## 6. 차별성

- **기존 서비스·해결방식과의 차이**: 인체 전용 상용 DB에는 없는 종(species) 축을 성분 단위로 결합 — 이는 조사 범위 내 경쟁 12개 도구 어디에도 없는 조합
- **우리가 제공하는 핵심 가치**:
  1. 위험과 기회를 분리해서 보지 않고 하나의 매트릭스로 교차 판단하게 함
  2. 산식·가중치를 전부 공개하고 사용자가 조정 가능
  3. 데이터 없음을 0점으로 위장하지 않고 NULL+커버리지%로 명시 — "위험이 없다"와 "확인 못했다"를 구분

## 7. 시장 및 사업기회

- **시장검증 과정에서 확인한 주요 근거**: 글로벌 동물약 R&D 지출 연 USD 30억, 한국 시장 1조 5,162억 원(+10.5%), R&D 집약도가 인체 대비 낮음(7~8% vs 20~27%) — 시장이 작다는 점을 전제로 접근
- **데이터에서 발견한 사업기회**: 인체 중심 제약 DB와 수의 진료 DB 사이에 "종을 반영한 초기 스크리닝" 공백이 존재하고, 이를 메우는 상용 도구가 없음
- **아직 추가 검증이 필요한 부분**: [추가 검증 필요] TAM/SAM/SOM 추정치(정보SW 지출 비중 1.5% 가정), 글로벌/국내 개발기업 총수(Green Book·공공데이터포털 실측 예정), 고객 인터뷰 0건 상태

## 8. 수익모델

- **누가**: 동물약 개발기업의 R&D팀 또는 조직 단위 계약 (개인 연구원이 아닌 팀/부서 예산으로 결제될 가능성 — [추가 검증 필요])
- **무엇에 대해**: 성분 스크리닝 조회 및 근거 리포트 접근권
- **어떤 방식으로 비용을 지불하는지**: [추가 검증 필요] — 확정된 가격 정책 없음. 참고로 조사된 경쟁 도구 가격대는 Clarivate 계약 중간값 연 $175,931, PatSnap Life Sci Pro $400/월, Euretos Academic €1,200/년이나, 이는 벤치마크일 뿐 우리 가격 결정의 근거는 아님

## 9. 실행방안

- **초기 MVP에서 구현할 범위**: 엔드포인트 3개·화면 3개(S1 매트릭스, S2 상세+근거, S0 소개는 선택). 데이터소스는 잘라내는 순서(§4-6)에 따라 S3 비교 → 실시간 조회 → EPO 특허 → Green Book 순으로 제외 가능. 최소 유지 대상은 openFDA(R2)·Open Targets(R1)·Europe PMC(O1)
- **향후 확장 가능한 기능 또는 서비스**: S3 후보 비교, EPO 특허 밀집도(R4) 추가, Green Book 승인·철회 이력(R3·O3) 추가, 실시간 API 조회, 성분 동의어 사전 자동화

## 10. 핵심 사업가설

이번 사업에서 반드시 검증해야 할 가장 중요한 가설 1개:

> **"동물약 개발기업 R&D팀은 이 문제(위험·기회 데이터 분산)에 실제로 비용을 지불할 의사가 있다."**

시장 규모와 과학적 근거는 확인됐지만, 이 지불 의사 하나가 검증되지 않으면 나머지 전체가 무의미해진다.
